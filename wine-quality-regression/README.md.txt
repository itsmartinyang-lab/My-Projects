# Wine Quality Regression Analysis

This project analyzes the determinants of wine quality using physicochemical attributes from the UCI Wine Quality dataset.

## Authors
Hex Wu  
Jingzhi Zhang  
Martin Yang  

## My Contribution
Implemented regression modeling, exploratory data analysis, and model diagnostics.

## Methodology

We estimate multiple linear regression models relating wine quality to chemical properties such as:

- alcohol
- acidity
- sulfur dioxide
- chlorides
- residual sugar

Interaction terms between predictors and wine type are included to capture differences between red and white wines.

Model selection was based on AIC, BIC, and adjusted R².
